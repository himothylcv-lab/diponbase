DIP WEBSITE
===========

Static HTML/CSS/JS. No build step. Drag the whole folder into Netlify Drop
(app.netlify.com/drop), Vercel, Cloudflare Pages, or upload it to any host.

BEFORE YOU SHARE THE LINK
1. The share tags in index.html already point at https://diponbase.com.
   If the site ever moves, change those three URLs.
2. script.js -- fill in the LINKS at the top:
     trade     o1 token page or DEX link
     x         already set to https://x.com/DipOnBase
     contract  https://basescan.org/token/<DIP contract address>
     o1        o1 launch page
   Any link left empty shows "Link coming soon" instead of going nowhere.
3. Paste the live URL into https://cards-dev.twitter.com/validator or just
   post it in a draft tweet to check the preview card appears.
